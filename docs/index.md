# Home

**Influx TS Editor** is an editor for manipulation of **Field values** for Time Series **Fields** stored in an [Influx V2](https://docs.influxdata.com/influxdb/v2/) database. (See [InfluxDB data elements](https://docs.influxdata.com/influxdb/v2/reference/key-concepts/data-elements/)).    
The [InfluxDB V2 UI](https://docs.influxdata.com/influxdb/v2/get-started/#influxdb-user-interface-ui) itself allows visualization but not modification of Field Values.

For Resources, refer to the [influx_ts_editor GitHub Repository](https://github.com/signag/influx_ts_editor)
